# Flux — いまの色

`/flux` は、ローカル時刻と二十四節気に対応する和色を眺めるページです。ヘッダーのFluxから開けます。各節気に朝・昼・夕・夜の4セットを用意し、合計96セット・48色に拡張しました。[ユーザー提供の正本](flux-sekki-colors.md)の24セットは各節気の4セットのいずれかに保持し、追加した72文は季節と時間帯に合わせたサイト用の文章です。[全パレットと出典](flux-palettes.md)を別紙にまとめています。

## 日付と時刻

`client/src/lib/sekkiColors.ts` に24セットを暦年順で置いています。来訪者の端末の月日以前で最も新しい開始日を選び、年初の1月1日〜4日は循環するテーブルの末尾の冬至になります。天文計算は行わず、画面下部の「節気の始まりは、暦の目安です。」で簡略化を示しています。

`client/src/lib/fluxPalettes.ts` で節気と時間帯の組み合わせを選びます。朝5〜10時、昼10〜16時、夕16〜19時、夜19〜翌5時の4区分です。同じ節気の約半月は同じ4セットで循環し、次の節気に入ると別の4セットへ切り替わります。リロードでランダムに変わることはありません。時間帯も既存の分境界タイマーで評価し、背景・和名・1文を4秒でクロスフェードします。

時計はローカル時刻の24時間制HH:MMです。秒は表示せず、毎秒のポーリングも行いません。次の分までの残り時間でタイマーを設定し、その都度実際の現在時刻・日付・節気を評価して張り直します。非表示タブから戻ったときやウィンドウへフォーカスが戻ったときも現在時刻に合わせます。ページを離れるとタイマーとイベントを解除します。

## 表示と動き

`client/src/pages/Flux.tsx` が時計と新旧の表示レイヤーを持ち、`client/src/flux.css` が画面と演出を担当します。新しい画像・フォント・依存は使いません。Flux自身の表示にはAPIやDBへのアクセスがありません。

背景は、和色とクリームの`color-mix`を使った3層のラジアルグラデーションです。色の濃い部分は左上に寄せ、文字が載る領域を淡く保ち、文字色は常に墨色`#2E2D29`です。グラデーション境界に全画面のぼかしフィルターは使いません。

濃い紺などの追加色にも対応するため、最も濃い層の混色は和色45%・クリーム55%に調整しました。文字色は共通のまま、全48色で小さな文字のコントラスト下限4.5を確保します。

- 最初の背景は3.2秒でscaleとopacityを変え、和名は1文字ずつ120msずらして表示します。文章は1.8秒後から2秒で現れます。文字は最初からDOMに存在します。
- 背景3層は60・90・140秒の往復、ハイライトは12秒の呼吸です。漂いの位置変更はtransformだけで行い、フレームごとのJavaScript処理はありません。
- 分の切り替えは800msで新旧の数字を重ねます。節気の切り替えは4秒で背景・和名・文章を重ねます。背景の旧レイヤーを不透明で残すため、途中で白く抜けません。
- モーション軽減時は全演出を無効にし、文字と静止背景を最初から表示します。時刻と節気の更新は続けます。
- 外部から入ったときの共通入場演出中は、Flux側の演出を一時停止し、入場後に続きを表示します。

通常ページの到着演出をFluxだけ解除し、共通ヘッダー以外の領域を画面高に合わせています。通常フッターの代わりに暦の注記を最下部へ配置します。低い画面では和名と余白を調整し、さらに狭い環境や文字拡大時は内容を切らずに縦スクロールできます。縦書きの節気はPCで読み上げ対象とし、モバイルでは日付行の節気表示にまとめます。

スタイルは既存テストの読み込み順契約を保つため、`index.css`のimport群の末尾にある`depot-motion.css`の直前に追加しています。Flux専用クラスを使い、他のページに演出や色を適用しません。

## 検証と更新

節気の完全性・正本との一致・全24境界・年跨ぎ・代表日・HH:MMと分境界は`client/src/lib/sekkiColors.test.ts`で検証します。ブラウザー検証は`node scripts/verify-flux.mjs`です。ChromeとPlaywrightが必要です。出力先は`.tools/flux-verified/`で、画面画像と検証結果を保存します。

公開への反映には、従来どおり`pnpm build`で更新パッケージを生成し、`dist/update.zip`の中身をXServerの`public_html`へ上書きします。配布の許可リストは変更していません。GitHubへの反映だけでは公開サイトは変わりません。今回の変更はローカルChromeで検証し、公開サーバーと実機Safariでの表示は未検証です。

96セットへの拡張では、型チェック、Vitest 38ファイル163件、配布処理3件、ビルドが通過しました。色と言葉の時間帯の微調整後にも、パレット・暦の26件を再確認しています。Chromeでは指定6画面幅に加えて320×568・375×667・768×600・1280×720を確認しました。全96セットを320px幅で検証し、朝・昼・夕・夜の4境界、分・日付・節気の切り替わり、モーション軽減、キーボード・タッチ操作も通過しています。全48色のコントラスト下限は4.85以上で、画面画像も目視確認しています。ブラウザー検証のAPIは503に固定し、Flux自体がAPIを呼び出さないことを確認しました。

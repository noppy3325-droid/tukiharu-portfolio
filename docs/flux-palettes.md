# Fluxの季節と時間帯のパレット

24節気それぞれに朝・昼・夕・夜の4セットを用意し、合計96セット・48色を表示する。同じ節気の約半月は同じ4セットを使い、次の節気でローテーションを切り替える。日替わりやランダム選択はしない。

朝は5:00〜9:59、昼は10:00〜15:59、夕は16:00〜18:59、夜は19:00〜翌4:59。来訪者のローカル時刻を使い、日の出・日の入りの天文計算は行わない。

[元の24セット](flux-sekki-colors.md)は、各節気の4セットのいずれかにそのまま保持している。追加の24色の名称と数値は[NIPPON COLORS](https://nipponcolors.com/)の公開配色値を参考にした。追加72文は季節と時間帯に合わせたサイト用の創作で、歴史的な文章の引用ではない。色の選定と季節・時間帯への割り当てはこのサイト独自の編集。

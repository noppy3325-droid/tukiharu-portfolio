# Galleryの撮影情報の自動入力

GalleryでJPEG・PNG・WebPを選ぶと、最適化前の元画像のEXIFから、撮影日時、カメラ・レンズ名、焦点距離、絞り値、シャッタースピード、ISO感度を読み取ります。画像に含まれている項目だけを使い、ファイルの更新日時から撮影日時を推測しません。

## 1枚ずつ登録する場合

ファイルを選ぶと、読み取れた撮影情報をプレビューの下に表示します。「サーバーへアップロード」を押すと画像URLと一緒に撮影詳細の入力欄へ反映し、詳細欄を開きます。内容を確認・修正してから「写真を追加」または「変更を保存」を押してください。

EXIFのない画像もアップロードできます。撮影詳細を手動入力するか、「詳細なし」を選べます。外部画像URLの入力では、ファイルを読み取らないため自動入力は行いません。すでに登録済みの写真にも、元画像を選び直さない限り自動補完は行いません。

## 複数画像を登録する場合

標準設定の「元画像の撮影情報を自動入力」では、同時に選んだ写真ごとに別々の撮影情報を登録します。タイトルとキャプションは共通です。

- 「共通値で上書き」では、入力した項目だけを全画像へ適用します。未入力の項目には、それぞれの元画像の情報を使います。
- 「詳細なし」では、自動読取結果を含めて撮影詳細を登録しません。
- 保存後に1枚の情報を修正したい場合は、Galleryの一覧からその写真を編集します。

## 日時と位置情報

撮影時刻は秒まで扱います。EXIFにタイムゾーンがあればその情報を使い、編集欄には操作している端末の現地時刻で表示します。タイムゾーンがないEXIFは、カメラに記録された時刻を端末の現地時刻として扱います。撮影した地域と編集端末のタイムゾーンが違う場合は、保存前に確認してください。

GPS座標は撮影詳細へ取り込まず、撮影場所も自動入力しません。位置を紹介したい場合は、撮影場所欄へ手動で入力します。

## 実装の流れ

```text
元画像File
  → ブラウザ内でExifReaderを必要時に読み込む
  → 元画像のEXIFから必要な項目だけをフォーム用データへ変換
  → 既存の画像最適化・アップロード
  → 撮影情報を編集・確認
  → PHP APIが文字列の形式・長さと権限を確認
  → SQLiteのGalleryレコードのJSONへ保存
  → 公開Galleryと拡大表示に撮影詳細を表示
```

[ExifReader](https://github.com/mattiasw/ExifReader)は、現在アップロードで受け付けているJPEG・PNG・WebPのEXIFに対応するため採用しています。元画像のメタデータ読み取りはブラウザ内で行い、外部サービスへ送信しません。管理画面でファイルを選んだときだけライブラリーを読み込み、通常の公開ページの初期読込には含めません。

サーバーで縮小・再保存した画像は元のEXIFを保持する前提にせず、必要な情報をDBへ別途保存します。元のメタデータを丸ごとDBへ保存することもありません。読取に失敗しても画像アップロードは継続します。

主なコードは[photoMetadata.ts](../client/src/lib/photoMetadata.ts)、[AdminImageUpload.tsx](../client/src/components/AdminImageUpload.tsx)、[AdminBatchImageUpload.tsx](../client/src/components/AdminBatchImageUpload.tsx)、[Admin.tsx](../client/src/pages/Admin.tsx)、[PHPのrecordInput](../xserver/public/api/bootstrap.php)、[Photos.tsx](../client/src/pages/Photos.tsx)です。

現在のXServer用SQLiteでは、GalleryのJSONに項目を追加して保存するため、既存DBのテーブル移行は不要です。旧Node.js・MySQL構成を別途使用する場合は、型定義に合わせて`galleryItems`へ`focalLength`、`aperture`、`shutterSpeed`、`iso`のnullableな`varchar(80)`列を追加する必要があります。XServer構成では旧MySQL用の移行コマンドを実行する必要はありません。

公開サイトへ反映するには、ビルドした`dist/update.zip`の内容を上書きします。サーバーの`uploads`や非公開DBを削除せず、[XServer運用ガイド](XSERVER.md)の更新手順を使用してください。

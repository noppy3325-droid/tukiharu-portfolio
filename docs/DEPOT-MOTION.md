# 「資材置き場の手続き」

静かなアーカイブの中で、紙を取り出す・整理する・線を引く手つきを加える演出レイヤーです。依存関係、画像、フォント、公開API、DB、登録データは追加・変更していません。

## 3つのフェーズ

1. **核**：220ms・8pxの紙の到着、見出し下とHomeのミシン目、外部リンクの鉛筆線。既存の離脱処理は180msのままです。
2. **個性**：見出しの線画アイコン、マウス限定の控えめなカードの影、時間帯による薄い光。
3. **締め**：読み込み中の細い線、フッターのページ名・公開日の整理番号行。

演出の定義は `client/src/depot-motion.css` にまとめ、フェーズごとにコメントで分けています。元の到着キーフレームは残して上書きします。到着の終了状態が離脱時のopacityを妨げないよう、離脱中だけ到着アニメーションを解除しています。離脱の条件・待ち時間を処理する `PageTransition.tsx` は変更していません。従来フェード対象外のナビゲーションやルーター内リンクも、そのままの挙動です。

## 挙動の詳細

- 見出しにはWorks＝かばん、Gallery＝カメラ、Blog＝紙の線画アイコンを添えています。既存のLucideだけを使い、枠・回転・アニメーション・重複した文字は付けません。装飾として `aria-hidden` を設定しています。初版の整理スタンプと表示済みフラグの処理は削除しました。
- 部屋の光は、マウント時のローカル時刻を一度だけ読みます。6時以上11時未満がmorning、11時以上17時未満がday、それ以外がeveningです。タイマーはありません。既存のカード色と水色・ピンク・背景色から作る30%以下の薄いグラデーションを一層重ね、ベースの背景色と文字色を保持しています。
- 棚の演出はマウスを使える環境のホバーに限定した薄い影です。Worksの傾き・白い光沢とWorks/Galleryのラベル色変化を外し、写真・説明の上に演出が重ならないようにしています。カード内には14〜20pxの余白を確保し、Worksのサムネイルは16:10の枠内で画像全体を表示します。Galleryは写真本来の縦横比を維持します。`TiltCard.tsx` の処理・APIは変更せず、Worksでの表示だけをCSSで静止させています。
- 鉛筆線はWorksの外部リンク、Aboutの外部リンク、フッターのREADMEに適用しています。キーボードでは線と2px・オフセット3pxのフォーカス輪郭を併用します。ヘッダーとモバイルメニューには適用していません。
- 読み込み線は幅をアニメーションさせず、静的に確保した線の `scaleX` を0から1へ変えます。600msで一度だけ終了し、そのまま残ります。これはブリーフの幅・高さをアニメーションさせない条件に合わせた実装です。
- 公開日は `shared/site.ts` の既存定数を使います。フッターの整理番号行にはリンクを付けていません。

## アクセシビリティ

CSS末尾に共通のreduced-motionブロックを置いています。新しい装飾だけに `.depot-motion` を付け、その子孫のアニメーション・トランジション・transformを解除します。ページ本体の到着・離脱も別途解除します。ページ全体を `.depot-motion` で囲まないため、既存の搭乗券の紙やプリンターのスタイルにリセットが波及しません。

線画アイコン、ミシン目、読み込み線は読み上げ・Tab移動の対象外です。既存のスキップリンク、モバイルメニューとそのフォーカス移動は保持しています。

## 検証（2026年11月2日）

型チェック、Vitest全132件、ビルド、配布テスト3件が通過しました。最後のCSS調整後には、追加した6件と既存のページ遷移3件・SEO2件を改めて確認しています。PageTransition、TiltCard、BoardingPassとそのCSS、package.json、ロックファイル、配布スクリプト、SEOのHTMLは作業前後のハッシュが一致しています。

Chromeでは検証用PHP・SQLiteを使い、次の項目を段階別に確認しています。公開サイトは比較画像の取得のみです。

- Home / Works / Gallery / Blog / About × 320・375・430・768・1024・1440px × 日本語・英語の60組で、横方向のはみ出し、見出し、ヘッダー操作の重なりを確認。
- 控えめな影がカード寸法・レイアウトシフトに影響せず、Worksの傾きと光沢がないこと。
- 鉛筆線、キーボードのフォーカス輪郭、スキップリンク、装飾のaria-hidden、重複したスタンプ文字の削除。
- 実際のフェード対象リンクで180msの離脱とopacity変化、220msの到着。
- 実際のルート用ファイルを遅延させたSuspenseで、600ms・一回限りの読み込み線。
- 6・10・11・16・17・23時での時間帯区分。3種類の光で、文字色を変えず、最大濃度の合成背景でも文字コントラストが低下しないこと。
- タッチのエミュレーションで影・傾きが残らず、メニューと写真拡大が操作できること。
- reduced-motionで新しいanimation・transition・transformが解除され、ホバーが即時に変わり、ページ移動が離脱待ちに入らないこと。

再実行用スクリプトは `scripts/verify-depot-motion.mjs` です。ビルド・配布ファイルの生成後に実行し、必要に応じて `PHP_BIN` と `PLAYWRIGHT_MODULE` を指定します。出力は `.tools/depot-motion-verified/`、検証サーバーはローカル8082番です。実機のiPhone・iPad・Safariは未検証です。

## 公開への反映

この実装だけでは公開サイトは変わりません。`pnpm build` で生成する `dist/update.zip` の中身を、従来の手順でXServerの `public_html` に上書きします。アップロード先を削除・ミラーリングせず、既存のuploadsと非公開DBを保持してください。配布スクリプトの許可リストは変更していません。


### カードと見出しの調整

2026年11月2日、ホバーが強すぎてカードが切り取られたように見えるとのフィードバックを受け、影・余白・画像の収まりを修正しました。Worksの傾きと白い光沢を無効にし、カードの影は3px/12px・既存の文字色の6%まで抑えています。文字入りの斜めスタンプは、静止した線画アイコンへ置き換えました。

### 入場演出の再生条件（2026年11月7日）

入場演出はアプリ全体に配置し、外部リンクやURLの直接入力で開いたときに、Home・About・Works・Gallery・Blogなどの入口で再生します。同じタブで以前に見ていても、外部から改めて開けば再生します。タブ単位の表示済みフラグは使いません。

サイト内のページ移動は、ページ全体を読み込むリンクでは参照元の同一オリジン判定、アプリ内の移動ではコンポーネントを再配置しないことで再生を防ぎます。再読み込みと履歴の戻る・進むでも再生しません。ブラウザーが参照元を提供しない通常のアクセスは、URLの直接入力として扱います。

スキップボタンとクリック・タッチ・キー入力による省略はありません。約3.2秒で終了し、演出の裏にあるリンクへの誤クリックを防ぎます。動きを減らす設定では再生せず、素材を1.2秒以内に読み込めなければ通常のページを表示します。演出途中にアプリ内のページが切り替わった場合は、その場で演出を終了します。

Chromeのローカル検証では320・375・430・768・1024・1440pxで各入口の再生と横方向のはみ出しを確認しました。外部からの再入場、サイト内リンク、再読み込み、履歴移動、途中の経路変更、スキップ操作の撤去、縦横のズーム、低速読み込み時の通常表示も検証しています。入場条件の検証ではAPI応答を503に固定し、投稿データの有無に依存しないことを確認しています。公開サーバーと実機Safariでの今回の変更は未検証です。

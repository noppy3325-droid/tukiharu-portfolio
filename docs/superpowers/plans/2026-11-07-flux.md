# Flux Implementation Plan

**Goal:** 二十四節気の正本24セットを使い、時刻と季節の色をゆっくり眺める `/flux` を追加する。

**Architecture:** 既存のReact・TypeScriptと共通ヘッダーを使う。静的な節気データとローカル日付だけで表示を決定し、時計は次の分の境界で再評価する。CSSレイヤーで背景、文字、時刻を遷移させる。

**Spec:** ユーザー添付の指示書と、同じ会話で提供された `flux-sekki-colors.md` の全24セット。

## Constraints and decisions

- 正本の色・読み・1文を変更しない。API、DB、依存、画像、フォント、配布許可リストを追加・変更しない。
- 共通レイアウトにFlux用の表示モードを設け、ヘッダー以外の領域を残りの画面高に合わせる。Fluxでは通常のフッターを出さず、指定の暦の注記を最下部に置く。
- 通常ページの220ms到着アニメーションをFluxだけ解除する。外部からの共通入場演出は維持する。
- 背景位置の漂いは、指示書の「transformとopacityのみ」を優先し、ラジアル層の位置をtransformでごく小さく移動する。
- 節気のクロスフェードでは古い背景を残し、その上に新背景を重ねて4秒で表示する。文字は新旧を4秒で重ねて入れ替え、白抜けを防ぐ。
- キーボードとタッチで既存ナビを維持する。6項目になったヘッダーは768pxを含めて検証する。
- privateなローカル設定と既存の未コミット変更を保持する。今回コミット・push・公開はしない。
- 検証で既存のスタイル順テストが「depot-motionを最後に読む」ことを要求していると判明したため、既存テストを変更しない条件を優先し、Fluxはその直前にimportする。専用クラスの詳細度で通常ページの到着演出から独立させる。

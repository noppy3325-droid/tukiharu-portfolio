# コード整理とサイト点検

既存機能・保存データ・デザインを維持し、確認できる不具合と重複する処理を対象に整理する。秘密のローカル設定と既存の未コミット変更には触れない。今回コミット・公開は行わない。

- ナビ項目と現在地判定を一箇所へまとめ、未設定のページタイトルを補う。
- Fluxの分境界タイマーとクロスフェードを専用フックへ分離し、待機中の不要タイマーを減らす。
- 同一文書のアンカーをフェード対象から外し、離脱タイマーを後片付けする。
- 保存機能が制限された環境でも記事を読めるよう、訪問者キーの保存を任意にする。HTTPSでないLAN確認でもUI用IDを生成できるようにする。
- 記事移動時に「いいね」、コメント下書き、編集・取り消し状態をリセットする。コメント入力に明示的なラベルを付ける。
- Homeに残った廃止済みBooks用サムネイルと到達不能分岐を除き、記事の代替画像を記事用SVGへ統一する。
- 型チェック、全テスト、PHP/配布検証、ブラウザーでの全公開ページ×6画面幅と主要操作を確認。Fluxと共通入場演出の検証も継続する。Safari実機と公開サーバーは対象外として明記する。

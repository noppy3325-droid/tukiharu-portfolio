# Fluxの色と言葉の拡張

朝・昼・夕・夜の4セットを節気ごとに用意し、24節気×4＝96セットとする。同じ節気の約半月は同じ4セットで循環し、次の節気で組み合わせを変更する。候補を日替わりやランダムにはしない。

元の正本24組は各節気の4組のどれかとして保持する。追加24色はNIPPON COLORSの公開配色値を参照し、合計48色とする。追加する72の文章は、節気の自然とその時間帯に合わせて作成する。これらは歴史的な引用ではなくサイト用の創作。

時間帯は端末ローカルの朝5〜10時、昼10〜16時、夕16〜19時、夜19〜翌5時。既存の分境界タイマーで判定し、時間帯・節気の境界で4秒のクロスフェードを使う。静的データだけを使い、外部API・保存状態・依存を追加しない。

検証は96件の完全性、48色、元24組の維持、時間帯の境界、節気の約半月の固定、年跨ぎを対象にする。6画面幅、長い名称、時間帯の遷移、モーション軽減、全色の可読性をブラウザーで確認する。

完了。型チェック、全163テスト、配布3テスト、ビルドが成功。レビューで立秋の元の夕日の文章を夕へ割り当てる指摘を受け、昼には白緑と新しい昼の文章を配置した。調整後にもパレット・暦の26テストが成功。Chromeで96セットすべての320px表示と全48色のコントラスト下限4.85、6画面幅、4つの時間帯境界で4秒のクロスフェードを確認した。更新用ZIPを生成済み。公開サーバーと実機Safariは未検証。
